# Mohammed Thariq E — Technical Architect portfolio

A responsive, static portfolio site for GitHub Pages. It uses plain HTML, CSS, and JavaScript—no build step or dependencies required. The visual design is intentionally polished and the copy is kept free of invented employers, credentials, dates, or project results.

## Personalize before sharing

Search `index.html` for the following prompts and replace them with accurate information:

- `ADD YOUR LOCATION`
- `ADD COMPANY NAME`, `ADD LOCATION`, and `ADD ... ROLE` / date prompts in the experience timeline
- The case-study prompts, project years, and outcome statements in **Selected work**
- `your.email@example.com` with your preferred public contact email
- `your-linkedin` with your LinkedIn profile slug (used in both links)
- The résumé request button with a link to a résumé PDF, if you want to publish one

Review the headline, summary, focus areas, and all links before promoting the site. Keep confidential employer or client details off the public site; use metrics only when they are accurate and appropriate to share.

## Publish with GitHub Pages

1. Commit these files to the repository's `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment and open the URL shown in the Pages settings.

The site is plain static content; no package installation or compilation is needed. Google Fonts are loaded remotely, with system sans-serif fallbacks if they are unavailable.
